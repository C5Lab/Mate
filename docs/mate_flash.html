  • ROM mode: hold BOOT, plug the board in, then release (some boards enter it automatically).
  • Close serial hogs: quit any monitor/qFlipper/IDE holding the COM port.
  • Stuck? unplug, click Connect again, replug with BOOT held, then Flash.
  • Reset: after flashing, press RESET if the board doesn't auto-reboot.

What happens

esptool-js enters the ROM stub, sets the baud rate, then writes each image at the offsets from manifest-<board>.json — bootloader, partition table, app and the SPIFFS web UI. Progress and MD5 checks mirror the Python esptool flow.

Need offline / no Web Serial?

Grab the per-board ZIP from the GitHub Release and run the bundled flash_board.py. It auto-installs esptool + pyserial and knows the same offsets.

Browser support

Chrome or Edge on desktop over HTTPS. Web Serial is required. On Firefox/Safari or mobile the flasher can't open a serial port — use flash_board.py instead.
